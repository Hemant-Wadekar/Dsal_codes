# SPPU SE - Data Structures and Algorithms Lab (DSAL)

Practical implementations and lab assignments for the **Second Year (SE) DSAL** course under **Savitribai Phule Pune University (SPPU)**.

---

## 🛠️ Languages & Tools

- **Languages:** C++, Python
- **Environment:** GCC/G++, Python 3.x, Linux Terminal / VS Code

---

## 📂 Topics Covered

* **Trees & Search Trees:** Binary Search Tree (BST), Expression Trees, Threaded Binary Trees (TBT)
* **Graphs:** Graph Traversals (DFS & BFS), Minimum Spanning Tree (Prim's & Kruskal's)
* **Hashing & Tables:** Hash tables with linear probing and collision handling
* **Advanced Structures:** AVL Trees, Max/Min Heap (Heap Sort)
* **File Handling:** Sequential and Direct Access file management
